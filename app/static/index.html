{

  • 扫掠区 = 测线按半扫宽（swath/2）缓冲、平头端帽。
  • 修改输入后约 0.7s 自动重新复核，结果确定性更新。

逐测线统计

采集连续性检查

粘贴按采集顺序排列的样本 JSON（数组或含 samples 的对象）；计划测线沿用上方任务输入中的 lines。事件轨迹以青色叠加在上方画布，点击事件卡片自动定位。

样本格式与检查规则 
[
  { "line_id": "L1", "timestamp": 0, "ping_seq": 1,
    "x": 0, "y": 45 },
  ...
]
  • 样本必须按采集顺序排列，后端不做重排；索引为 0-based 原始输入顺序。
  • 顺序检查：相邻样本时间倒退；同一测线内 ping_seq 重复或非 +1 跳变（换线重新计数属正常）。
  • 区间检查（仅同测线且时间严格递增的相邻样本间）：间隔 > 最大采样间隔、速度 > 最大速度、到计划测线（start-end 线段）的距离 > 偏离容差。
  • 相邻异常区间合并为事件：不跨测线、不跨时间倒退点；同一区间命中多条规则时原因全部保留。
  • 样本/阈值修改后约 0.7s 自动重新检查；任务输入中的测线变化后也会自动重查。
逐测线统计

交叉点水深闭合

粘贴按采集顺序排列的水深样本 JSON（数组或含 samples 的对象，样本含 line_id / x / y / depth）；计划测线沿用上方任务输入中的 lines。 仅处理两条计划线的点状交点：每线按原始顺序寻找投影里程跨过交点、 两端投影里程到交点里程的绝对差（沿线距离）均不超过包围距离的同线相邻样本，按里程线性插值水深； 交点水深差建立偏置方程网，Huber 迭代加权最小二乘估计测线偏置。有效交点以彩色圆点叠加在上方画布。

样本格式与计算规则 
[
  { "line_id": "H1", "x": 0, "y": 120, "depth": 20.0 },
  ...
]
  • 样本必须按采集顺序排列，后端不做重排；端点索引为 0-based 原始顺序。
  • 仅处理两条计划线的点状交点；共线/重叠线整对跳过并说明原因。
  • 每线寻找投影里程跨过交点、两端投影里程到交点里程的绝对差（沿线距离）均 ≤ 包围距离的同线相邻样本对（端点贴近测线但沿线离交点过远同样超距拒绝，横向投影距离不参与判限）；多组候选取两端沿线距离之和最小者，再以原始索引破同值；水深按里程线性插值。
  • 偏置方程 b₁−b₂ = d₂−d₁，每连通分量固定字典序最小测线偏置为零，NumPy Huber IRLS 求解；观测数 = 节点数−1 的分量标“无冗余不可判”，其余按 |校正残差| 与阈值判定。
  • 样本/阈值修改后约 0.7s 自动重新闭合；任务输入中的测线变化后也会自动重算。
