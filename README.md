# 水下声呐测线覆盖复核

粘贴任务边界与按顺序记录的测线（端点 + 扫宽）JSON，系统自动完成覆盖复核：

- 将每条测线按 **半扫宽缓冲** 成扫掠区域（平头端帽），求并集得到总覆盖；
- 计算扫掠并集与任务边界的 **差集**，识别 **未覆盖缺口**（界内）与 **边界外扫掠**（越界）；
- 对 **相邻测线**（记录顺序中的 Lᵢ 与 Lᵢ₊₁）求交，识别 **过度重叠**；
- 每个问题给出 **坐标（质心 + 多边形）、关联测线、可复核的计算依据**（方法公式 + 全部中间量）；
- 计算完全确定（无随机、无时间戳），**同一输入输出逐字节一致**，修改输入后结果稳定更新。

复核页下方另有 **采集连续性** 面板：粘贴按采集顺序排列的样本（line_id / timestamp / ping_seq / x / y），
沿用任务输入中的计划测线，检查时间倒退、序号重复/跳变、采样间隔超限、速度超限与偏离计划线超限，
相邻异常区间自动合并为事件（详见下文）。

复核页最下方另有 **交叉点水深闭合** 面板：粘贴按采集顺序排列的水深样本
（line_id / x / y / depth），沿用任务输入中的计划测线，仅处理两条计划线的点状交点，
按里程线性插值交点水深，以交点水深差建立偏置方程网，用 NumPy Huber 迭代加权最小二乘
估计各测线偏置并判定闭合异常（详见下文）。

复核页再下方另有 **声速射线改正** 面板：给出分层声速剖面（连续、不重叠、允许断档）与
多波束波束（位置/航向/换能器深度/双程传播时间/相对垂直方向的有符号入射角），
取单程时间并以入射层射线参数 `p = sin(θ)/c` 为 Snell 常量逐层追踪，输出改正落点、
各层角度/耗时/位移、射线路径以及入射声速直线传播对照值；遇折射极限、剖面断档或时间
超过剖面底界时该波束失败并保留已走层段，禁止外推（详见下文）。

技术栈：Python FastAPI + Shapely(GEOS) + NumPy 后端，原生 JavaScript（零依赖）前端。

## 快速开始（一条命令）

```bash
docker compose up --build
```

然后访问 <http://localhost:8000> 。页面自动载入示例数据并完成首次复核、连续性检查与声速射线改正（水深闭合面板可点“载入示例”）。

> 也可以 `docker build -t sonar-review . && docker run -p 8000:8000 sonar-review`。

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

```

## 输入格式

页面左侧文本框粘贴 JSON（点 **载入示例** 可查看完整样例）：

```json
{
  "boundary": {
    "type": "Polygon",
    "coordinates": [[[0, 0], [1000, 0], [1000, 500], [400, 500], [400, 600], [0, 600], [0, 0]]]
  },
  "lines": [
    {"id": "L1", "start": [0, 45], "end": [1000, 45], "swath": 90},
    {"id": "L2", "start": [1000, 135], "end": [0, 135], "swath": 90}
  ],
  "options": {"min_issue_area": 1.0, "max_overlap_ratio": 0.2}
}
```

| 字段 | 说明 |
| --- | --- |
| `boundary` | 任务边界，GeoJSON `Polygon`/`MultiPolygon` 几何对象 |
| `lines[]` | 测线，**按记录顺序排列**；`id` 唯一，`start`/`end` 为 `[x, y]`，`swath` 为全扫宽 |
| `options.min_issue_area` | 问题最小上报面积（默认 1.0），用于过滤碎斑 |
| `options.max_overlap_ratio` | 重叠率阈值（默认 0.2），超过判为过度重叠 |

**坐标约定**：输入视为平面坐标（如局部网格或投影坐标，单位通常为米），输出的长度/面积与输入单位一致。经纬度坐标请先投影，否则面积数值无物理意义。

## 计算方法与可复核依据

扫掠区：`buffer(line_i, swath_i / 2)`，平头端帽（cap_style=flat）。

| 问题类型 | 几何定义 | 上报内容 |
| --- | --- | --- |
| 未覆盖缺口 `gap` | `boundary − ⋃扫掠区` | 面积、占边界面积百分比、质心、多边形、相邻测线及扫宽 |
| 边界外扫掠 `outside` | `⋃扫掠区 − boundary` | 面积、占覆盖并集百分比、逐测线分摊面积（`buffer(line) ∩ 越界区块`，重叠部分会重复计数，依据中已注明） |
| 过度重叠 `overlap` | `buffer(Lᵢ) ∩ buffer(Lᵢ₊₁)` | 重叠面积、重叠率 `overlap_area / min(两扫掠面积)`、中心线间距、各自扫宽与缓冲面积、阈值 |

每个问题的 `basis` 字段包含方法公式与全部中间量，可用任何 GIS/几何工具独立复算。
严重度分级：缺口按占边界面积（≥5% 高 / ≥1% 中）；越界按占覆盖并集（≥2% 高 / ≥0.5% 中）；重叠按重叠率（≥0.5 高 / ≥0.3 中）。

**稳定性**：问题按类型分组、组内按质心坐标升序编号（GAP-001…），坐标输出保留 6 位小数、数值 4 位小数，同一输入的输出逐字节一致；修改输入后约 0.7 秒自动重新复核。

## 采集连续性检查

页面下方 **采集连续性** 面板：粘贴 **按采集顺序排列** 的样本 JSON（纯数组，或含 `samples` 数组的对象），
设置三个阈值（最大采样间隔、最大速度、偏离容差），点 **开始检查**。
计划测线直接 **沿用上方任务输入中的 `lines`**，无需重复粘贴；任务输入变化后连续性结果自动重查。

```json
[
  { "line_id": "L1", "timestamp": 0, "ping_seq": 1, "x": 0, "y": 45 },
  { "line_id": "L1", "timestamp": 5, "ping_seq": 2, "x": 50, "y": 45 }
]
```

| 字段 | 说明 |
| --- | --- |
| `line_id` | 所属测线，应对应任务输入 `lines[].id`；未知测线的样本不参与偏离判定，列入 `summary.unknown_line_ids` |
| `timestamp` | 采样时间戳（秒，epoch 或相对秒均可），采集顺序下应非递减 |
| `ping_seq` | ping 序号，同一测线内应逐个 +1（换线重新计数属正常） |
| `x` / `y` | 平面坐标，与计划测线同一坐标系 |

**检查规则**（样本不重排，索引为 0-based 原始输入顺序；区间 k 连接样本 k-1 与 k）：

| 规则 | 判定 | 适用范围 |
| --- | --- | --- |
| 时间倒退 `time_reversal` | `timestamp[k] < timestamp[k-1]` | 任意相邻样本 |
| 序号重复 `seq_duplicate` | `ping_seq[k] == ping_seq[k-1]` | 仅同测线相邻 |
| 序号非 +1 跳变 `seq_jump` | `ping_seq[k] ≠ ping_seq[k-1] + 1`（且不相等） | 仅同测线相邻 |
| 采样间隔超限 `gap_exceeded` | `dt > max_gap_s` | 仅同测线且时间严格递增的区间 |
| 速度超限 `speed_exceeded` | `dist / dt > max_speed` | 同上 |
| 偏离计划线超限 `offset_exceeded` | `max(两端点到计划线距离) > max_offset` | 同上（距离到 start-end 线段） |

**事件合并**：相邻异常区间合并为一个事件，**不跨测线、不跨时间倒退点**（跨线/倒退区间独立成事件并作为合并边界）；
同一区间命中多条规则时原因全部保留。每个事件给出：起止样本与原始索引（`start_index`/`end_index`）、
原因列表、轨迹几何（GeoJSON LineString）、阈值、计算量（各区间 dt/位移/速度/两端偏离及事件最大值），
事件按起始索引升序编号（EVT-001…），同一输入输出逐字节一致。

**页面操作**：事件可按 **测线** 和 **原因** 组合筛选（计数联动）；点击事件卡片在上方画布 **定位高亮**
其轨迹（青色线+样本点）；**导出结果 JSON** 下载完整响应（含全部区间明细与计算依据）；
样本或阈值修改后约 0.7s 自动重新检查。

## 交叉点水深闭合

页面最下方 **交叉点水深闭合** 面板：粘贴 **按采集顺序排列** 的水深样本 JSON
（纯数组，或含 `samples` 数组的对象），样本在连续性字段基础上增加 `depth`；
设置 **包围距离、Huber 阈值 δ、校正残差阈值** 三个参数，点 **开始闭合**。
计划测线同样 **沿用上方任务输入中的 `lines`**；点该面板的 **载入示例** 会同时载入
配套的网格任务（3 横 × 3 竖 + 1 条共线重叠线）与含粗差的水深样本。

```json
[
  { "line_id": "H1", "x": 0, "y": 120, "depth": 20.0 },
  { "line_id": "H1", "x": 100, "y": 120, "depth": 19.2 }
]
```

| 字段 | 说明 |
| --- | --- |
| `line_id` | 所属测线，应对应任务输入 `lines[].id`；未定义的测线样本不参与插值，列入 `summary.unknown_line_ids` |
| `x` / `y` | 平面坐标，与计划测线同一坐标系 |
| `depth` | 该样本处水深（长度单位与坐标一致即可，不影响几何） |

**计算规则**（样本不重排，端点索引为 0-based 原始输入顺序）：

1. **点状交点**：枚举两两计划线（`LineString`）求交，相交结果为唯一一点（含端点相接）才处理；
   共线/重叠（相交为有长度的线几何）或多点相接整对跳过，原因记 `overlapping`；
   平行错开、共线但无重叠的线对不产生记录。点状交点按 `(x, y, 线名)` 升序编号 XPT-001…。
2. **包围样本与插值**：每条线按原始采集顺序扫描 **同线相邻样本对 (a, b)**，要求
   **投影里程跨过交点**（`min(sₐ,s_b) ≤ sₓ ≤ max(sₐ,s_b)`，允许采集方向与 start→end 反向）
   且 **两端投影里程到交点里程的绝对差（沿线距离 `|s − sₓ|`）均 ≤ 包围距离**——
   端点可能横向贴近测线但沿线离交点很远，横向投影距离不参与判限。候选超过一组时取
   **两端沿线距离之和最小** 者，再以 a（再 b）的原始索引破同值；水深按里程线性插值
   `d = dₐ + (d_b − dₐ)·t`，`t = (sₓ − sₐ)/(s_b − sₐ)`。任一参与线找不到有效包围样本时
   该交点跳过：该线 **没有任何采集样本** 记 `unknown_line`（未知测线/未采集），
   否则记 `no_bracketing_samples`（缺少有效包围样本），原因中给出交点、里程与阈值。
3. **偏置方程网**：每个有效交点（字典序 `li < lj`）列方程 `b_li − b_lj = d_j − d_i`，
   校正后交点残差 `r = (d_i + b_i) − (d_j + b_j)`。以交点为边做并查集分 **连通分量**，
   每个分量固定 **字典序最小测线偏置为零（锚线）**，消去基准列后用 NumPy 求解加权法方程。
4. **Huber IRLS**：初始权全 1，按残差更新权 `|r| ≤ δ → 1`，否则 `δ/|r|`，
   反复重解至权收敛（上限 50 次）。粗差观测会被自动降权。
5. **判定**：观测数 = 节点数 − 1 的分量是一棵树（只能闭合到零、无检核条件），
   其交点标 **`indeterminate` 无冗余不可判**；有冗余分量按
   `|校正残差| > 校正残差阈值` 判 `anomaly`（闭合异常），否则 `ok`。

**结果内容**：每个交点给出两线的 **插值端点（原始索引、坐标、里程、沿线距离 `alongtrack_distance_m`、
横向投影距离与到交点直线距离（仅参考）、水深）与比例 t、插值水深**，以及该线的包围对/有效候选对计数
与所用包围距离，另有 **原始闭合差、最终 Huber 权重、两线偏置、校正残差** 与所属连通分量；
跳过记录（SKP-001…）给出跳过类别与文字原因；`components` 给出每分量锚线、节点/观测数、冗余度、
IRLS 迭代次数、收敛情况与残差 RMS；`line_biases` 给出逐测线偏置（锚线标 ⚓）。同一输入输出逐字节一致。

**页面操作**：交点可按 **状态**（全部/正常/异常/不可判/跳过）与 **测线** 组合筛选（计数联动）；
有效交点以彩色圆点叠加在上方画布（黄=正常、红=异常、灰=不可判，橙色虚线圈=跳过），
点击卡片在画布定位并高亮；**导出结果 JSON** 下载完整响应；样本或参数修改后约 0.7s 自动重新闭合，
任务输入中的计划测线变化后也会自动重算。

## 声速射线改正

页面 **声速射线改正** 面板：左侧分别粘贴 **分层声速剖面** 与 **波束** 两段 JSON
（数组，或含 `profile` / `beams` 数组的对象），点 **开始改正**（修改后约 0.7s 自动重算）。
示例剖面在 300–320 m 间故意留有断档，并覆盖成功与全部三类失败波束。

```json
{
  "profile": [
    { "top_depth": 0, "bottom_depth": 15, "sound_speed": 1500.0 },
    { "top_depth": 15, "bottom_depth": 50, "sound_speed": 1480.0 }
  ],
  "beams": [
    { "id": "B-001", "x": 500, "y": 500, "heading": 90,
      "transducer_depth": 5, "two_way_travel_time": 0.16, "angle_deg": 30.0 }
  ]
}
```

| 字段 | 说明 |
| --- | --- |
| `profile[].top_depth/bottom_depth` | 层顶/层底深度（自海表面向下为正），层厚必须为正；层间不得重叠（整体 400 拒绝），端点相接允许 |
| `profile[].sound_speed` | 该层内恒定声速（长度/秒，与坐标长度单位一致），必须为正 |
| `beams[].id` | 可选波束编号；缺省按输入顺序生成 B-001… |
| `x / y` | 换能器平面坐标 |
| `heading` | 航向角（度，自正北顺时针） |
| `transducer_depth` | 换能器深度（向下为正；必须落在某一层内，否则该波束失败） |
| `two_way_travel_time` | 双程传播时间（秒）；后端取一半 `t = twtt/2` 作为单程时间 |
| `angle_deg` | 相对垂直方向的有符号入射角（度，−90…90），**正角指右舷** |

**射线追踪规则**（波束按 0-based 原始输入顺序处理，不重排）：

1. **入射层与射线参数**：取换能器深度所在层（位于相接界面时归属下方层）的声速 `c₀`
   与入射角 `θ₀`，计算 Snell 常量 `p = sin(θ₀)/c₀`，全程不变。
2. **逐层累计**：在声速 `c` 的层内 `sin θ = p·c`、`cos θ = √(1−(p·c)²)`；
   穿过垂深 `dz` 的单程耗时 `dt = dz/(c·cos θ)`，有符号横距 `dx = dz·tan θ`
   （`tan θ = p·c/√(1−(p·c)²)`）。换能器位于层中部时首段只走部分厚度；
   单程时间在某层内耗尽时该层同样只走部分厚度。
3. **平面落点**：正角指向右舷，右舷方位 = `heading + 90°`：
   `footprint.x = x + cross·cos(heading)`、`footprint.y = y − cross·sin(heading)`。
4. **失败（禁止外推，已走层段全部保留，不输出落点）**：
   - `refraction_limit`：入射层或任一界面处 `|p·c| ≥ 1`（全反射/临界折射）；
   - `profile_gap`：换能器深度不在任何层内，或某层底与下一层顶之间存在深度空缺（断档）；
   - `beyond_profile_bottom`：穿过最深层底后仍有剩余单程时间。
5. **直线对照**：只要能确定入射声速，就同时给出以 `c₀` 沿入射方向直线传播
   距离 `c₀·t` 的对照落点、对照垂深/横距，以及与改正落点的平面偏差 `deviation`。

**结果内容**：`summary`（波束数、成功/失败数、三类失败计数、剖面顶底深、最大对照偏差）、
`profile`（按顶深排序后的层，`layer_index` 为原始输入序号）、`beams[]`（状态、射线参数 `p`、
改正落点 `point`、落点深度、累计垂深/横距/单程耗时与剩余时间；`segments[]` 逐层给出
层序号/声速/层内角度（sin/cos）/进入离开深度/垂深/横距/路径长/层内耗时/累计耗时/是否完整层；
失败波束给出 `failure_reason/failure_message`、已到达深度与已走层段；`straight` 直线对照；
`ray_path.coordinates` 为 `[横距, 垂深]` 剖面折线）、`meta`（剖面/追踪/失败/平面换算规则文字）。
同一输入输出逐字节一致。

**页面操作**：波束可按 **状态**（全部/成功/失败/折射极限/剖面断档/超底界）筛选（计数）；
成功波束以绿色实心圆、直线对照以橙色空心菱形叠加在上方画布（含换能器→落点连线），
失败波束在换能器处标红叉；点击卡片在画布定位，并在下方 **射线路径剖面图** 中绘制
声速层带、断档红条、绿色 Snell 折线路径与橙色虚线直线对照；**导出结果 JSON** 下载完整响应。

| --- | --- |
| `GET /` | 复核页面 |

| `GET /api/ray-correction/sample` | 声速射线改正式例数据（profile + beams，含成功与三类失败波束） |
| `POST /api/ray-correction` | 声速射线改正，请求体 `{"profile": [...top/bottom/sound_speed...], "beams": [...x/y/heading/transducer_depth/two_way_travel_time/angle_deg...]}` |
| `GET /docs` | FastAPI 自动交互文档 |

响应：`summary`（面积/覆盖率/问题计数）、`issues`（含 `basis` 计算依据）、`line_stats`（逐测线统计）、`geometries.coverage`（覆盖并集，用于绘图）、`meta`（引擎版本与约定）。页面 **导出结果 JSON** 按钮下载的即该响应。
连续性接口响应：`summary`（样本/事件计数、各原因计数、未知测线）、`events`（起止样本、原始索引、原因、轨迹几何、阈值与计算量、逐区间明细）、`line_stats`（逐测线样本/事件统计）、`meta`（判定规则与索引约定）。
水深闭合接口响应：`summary`（点状交点/有效交点计数、正常/异常/不可判计数、跳过分类计数、连通分量数）、`intersections`（插值端点与比例、原始闭合差、最终权重、偏置、校正残差、状态）、`skips`（重叠线/缺有效包围样本/未知测线及原因）、`components`（锚线、节点/观测数、冗余度、Huber 迭代与收敛、残差 RMS）、`line_biases`（逐测线偏置）、`meta`（交点/包围/平差规则与编号约定）。
声速射线改正接口响应：`summary`（波束/成功/失败/三类失败计数、剖面顶底深、最大对照偏差）、`profile`（按顶深排序的层）、`beams`（改正落点、逐层角度/耗时/位移、射线参数、已走层段、失败原因、射线路径与入射声速直线对照）、`meta`（剖面/追踪/失败/平面换算规则与编号约定）。

## 页面功能

- 示例数据一键载入；输入修改后自动重新复核（防抖 0.7s），失败时保留上次结果并提示；
- 覆盖图：边界 / 扫掠覆盖 / 测线 / 三类问题分层着色，滚轮缩放、拖拽平移、双击复位，点击问题卡片自动定位高亮；
- 问题按类型筛选（全部 / 缺口 / 越界 / 重叠），附严重度标记；
- 逐测线统计表（长度、扫宽、扫掠/界内/界外面积）；
- 复核结果一键导出 JSON；
- 采集连续性面板：样本粘贴 + 三阈值设置，事件按测线/原因组合筛选、点击卡片画布定位、结果导出 JSON；
- 交叉点水深闭合面板：含 depth 样本粘贴 + 包围距离/Huber δ/残差阈值设置，交点按状态/测线组合筛选、
  点击卡片画布定位（有效交点彩色圆点、跳过点橙色虚线圈）、测线偏置与连通分量表、结果导出 JSON；
- 声速射线改正面板：声速剖面 + 波束粘贴，波束按状态/失败原因筛选，改正落点与直线对照叠加画布、
  失败波束红叉，点击卡片查看横距-垂深射线路径剖面图（声速层带/断档/Snell 折线/直线对照）、结果导出 JSON。
